## Project Overview

This project demonstrates a DevOps assignment implementation using Terraform, GitHub Actions, Python automation, and LocalStack. The infrastructure components were provisioned using Infrastructure as Code principles, while the Cost Janitor utility scans cloud resources and generates cleanup reports in JSON and Markdown formats.

---

## Features Implemented

- Terraform-based infrastructure setup
- Modular Terraform structure
- GitHub Actions CI workflow
- Python-based Cost Janitor utility
- JSON and Markdown report generation
- LocalStack integration support
- Documentation and architecture design
- Sample report generation
